状態: 実装仕様正本候補
対象Repository: `gatchimuchio/GUI-Shell`
主要開発環境: Windows
基底言語: 日本語

---

# 0. 目的

GUI-Shellを、

> 安全なRuntime / Agent操作基盤

から、

> Runtime、Agent、Tool、外部Protocol、資源、履歴、評価、資格情報、更新、通知、複数Hostを一元運用できる総合Control Plane

へ拡張する。

既存の、

* Authority（権限境界）
* Permission
* Approval
* Audit（監査）
* Recovery（復旧）
* Content Exposure（内容露出）
* Adapter（接続境界）
* Runtime（実行系）
* Broker（制御仲介）

の境界は維持する。

# 7. 作業領域インスペクタ

## 目的

Agentが何を変更・実行しているかをGUI上で追跡する。

## 最低機能

```text
作業領域
├─ ファイルツリー
├─ 変更ファイル
├─ 差分表示
├─ shell command履歴
├─ Tool呼出し履歴
├─ 試験結果
├─ Approval状態
├─ Auditリンク
└─ rollback候補
```

## 差分表示

* unified diff（統合差分）
* side-by-side diff（左右比較差分）
  -追加
  -削除
  -変更
* binaryは内容表示せずmetadataのみ

## 禁止

UIから直接filesystemを書き換えない。

RollbackはRecovery / Approval経路を通す。
