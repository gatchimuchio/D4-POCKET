# GUI-Shell 総合機能拡張 開発工程表 rev1

## 基本原則

各作業単位は必ず、

```text
調査
→ 日本語意味正本
→ Contract
→ 実装
→ 試験
→ 監査
→ commit
→ push
→ remote確認
```

で閉じる。

一括実装して最後にpushしない。
