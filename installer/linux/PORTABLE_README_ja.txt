D4 Pocket Linux portable package

このarchiveは未署名の開発・検証用です。正式配布物として使用しないでください。

対象:
  Ubuntu 24.04 LTS / x86_64
  GTK 3、GLib 2、ログイン中のD-Bus sessionが必要です。
  Credential機能にはSecret Service互換の資格情報保管サービスが必要です。

起動:
  1. デスクトップのファイルマネージャーで、このアーカイブを展開します。
  2. 展開先のD4Pocketフォルダーを開き、gui_shell_desktop_launcherを起動します。
  3. ファイルマネージャーが実行確認を表示した場合は、実行を選びます。
  4. 初回画面から導入する場合、表示されるBrokerのOwner確認を行います。

通常利用にPython、Rust、Flutter、Git、clone、terminalは必要ありません。
製品の導入、更新、rollback、削除はD4 Pocketの画面から開始し、BrokerのOwner確認に従います。
